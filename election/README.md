# Election Module

This folder contains the DepED USIS election system module.

## Run Locally

From the repository root:

```powershell
npm run dev:election
```

Or from inside this folder:

```powershell
npm install
npm run dev
```

## Notes

- This module is part of the unified `DepED USIS` repository.
- Shared backend configuration is centralized through the monorepo shared packages.
