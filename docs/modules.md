# DepED USIS Modules

## Active Modules

### `election/`

School election management module with voting, admin tools, tally monitoring, and reporting features.

### `registrar/`

Registrar and learner information module with enrollment, learner listing, section management, dashboarding, and bulk import features.

## Future Module Pattern

New systems should be added as sibling module folders or later under an `apps/` directory if the repository is restructured further.

Examples:

- `guidance/`
- `library/`
- `clinic/`
- `finance/`
- `student-portal/`
